# Final Project – Emotion Detection Web App

##  Overview
This project is a Flask-based web application that performs **emotion analysis** on user-provided text using an external Emotion Detection API. It identifies emotions such as anger, joy, fear, sadness, and disgust, and also returns the dominant emotion.

---

##  Features
- Accepts user text input via web interface or API
- Detects emotions using IBM Watson Emotion NLP service
- Returns:
  - Anger
  - Disgust
  - Fear
  - Joy
  - Sadness
  - Dominant emotion
- Handles invalid or blank input gracefully
- Simple web interface using Flask templates
